Alle Benutzeroberflächen müssen so konzipiert sein, dass sie auch im Querformat auf Mobilgeräten fehlerfrei und ohne Überlappungen dargestellt werden. Elemente wie Unterschriftenpads oder Eingabeformulare müssen sich an die verringerte vertikale Bildschirmhöhe anpassen. Feststehende Navigationselemente wie eine Bottom-Navigation dürfen wichtige Interaktionsbereiche nicht verdecken. Bei kritischen Ansichten, die viel Platz benötigen, muss die Layout-Struktur über Tailwind-Klassen (landscape:) so angepasst werden, dass Bedienelemente entweder ausgeblendet, verkleinert oder an den Seitenrand verschoben werden, um den Fokus auf die Hauptaktion zu bewahren.
