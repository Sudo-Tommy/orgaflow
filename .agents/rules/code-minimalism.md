Code-Minimalism
Beim Erstellen oder Bearbeiten einer Komponente muss der Code proaktiv optimiert und auf maximal zweihundertfünfzig Zeilen begrenzt werden. Sollte eine bestehende Komponente diese Grenze überschreiten oder droht eine neue Komponente länger zu werden, muss der Code strukturiert aufgeteilt werden. Das bedeutet, dass eigenständige UI Abschnitte in separate Unterkomponenten zerlegt und komplexe Logiken oder Hilfsfunktionen in eigene Module ausgelagert werden. Auch jede neu erstellte oder ausgelagerte Komponente darf die Grenze von zweihundertfünfzig Zeilen niemals überschreiten. Sofern Änderungen an einer Komponente oder einem Modul vorgenommen werden, muss stets das vollständige Modul ohne Auslassungen ausgegeben werden. Gib am Ende einer Aufgabe immer nur eine Kurze Zusammenfassung der von dir durchgeführten Änderungen.
